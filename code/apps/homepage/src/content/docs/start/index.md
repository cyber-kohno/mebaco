Mebacoを初めて使う場合は、Studioを起動して、[最初のProject](/start/first-project/)のCounterを作ってみてください。画面を組み、クリック処理を書き、Previewで動かして保存するまでを順に学べます。

## 学ぶ順番

1. [インストール](/start/install/) — 対応環境とStudioの起動方法
2. [最初のProject](/start/first-project/) — Counterを作り、クリックで値を変え、保存・再読込する
3. [Projectの構造](/concepts/project-model/) — App、Entry、Componentの関係
4. [StateとAction](/guides/state-and-actions/) — 操作に応じて画面を変える
5. [アプリを配布する](/guides/distribute/) — BundleとClientの使い方

## 困ったとき

Counter作成中につまずいた場合は、[チュートリアルの確認項目](/start/first-project/#うまくいかないとき)で、追加先・入力モード・実行対象を確認してください。その他のエラー表示は[トラブルシューティング](/troubleshooting/)、要素や設定を調べる入口は[リファレンス](/reference/)です。
