---
title: トラブルシューティング
description: インストール、編集、実行、保存、配布で困ったときの調べ方。
---

問題ごとに「症状 → 確認すること → 対処 → 追加で集める情報」を統一書式にします。

- Studioが起動しない、またはOSの警告が表示される
- Projectを保存・読込できない
- 要素を配置できない、または設定項目が無効になる
- 式の名前解決や型検証に失敗する
- PreviewでRuntime Errorが発生する
- BundleをClientにインストール・更新できない

公開版では、エラー文言をコードから収集し、検索可能な索引へ追加します。
