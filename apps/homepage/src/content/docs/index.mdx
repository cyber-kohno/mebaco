## アプリの構造を見ながら、動くものを作る

Mebacoは、ローカルで動作するデスクトップのアプリ開発環境です。画面や部品をツリーで組み立て、Stateやイベント処理を式・TypeScriptで定義し、同じStudioの中ですぐに動作を確かめられます。

<div class="home-grid">
  <article class="home-card"><h3>ツリーで構造を組む</h3><p>App、Component、画面要素、制御構造を一つのProjectとして俯瞰しながら編集します。</p></article>
  <article class="home-card"><h3>コードで振る舞いを書く</h3><p>State、Props、Functionなどを型情報付きで参照し、必要なロジックを記述します。</p></article>
  <article class="home-card"><h3>作ってすぐ動かす</h3><p>Runtimeでプレビューし、編集内容をすぐ確認します。Debug設定やログもProject内で扱えます。</p></article>
  <article class="home-card"><h3>部品を育てて配る</h3><p>ComponentやStyleを再利用し、BundleとしてアプリをまとめてClientから起動できます。</p></article>
</div>

<section class="home-section">

## Mebacoでの開発の流れ

1. Projectを作成し、Appと起点となるComponentを用意する。
2. UIをツリーに配置し、PropsやStyleを設定する。
3. StoreとStateを用意し、Actionや式で振る舞いを加える。
4. Runtimeで操作しながら確認し、Debug機能で問題を調べる。
5. Bundleを作成し、Clientでインストール・起動する。

<div class="site-callout">Mebacoは、見た目の配置だけでアプリを完成させるツールではありません。ツリー編集と型付きコードを組み合わせ、Projectの構造と動作を一緒に管理します。</div>

</section>

<section class="home-section">

## はじめての方へ

まずは[はじめ方](/start/)でStudioの全体像を確認し、[最初のProject](/start/first-project/)を作る流れをたどってください。各要素の設定を調べたい場合は[リファレンス](/reference/)から探せます。

### 対象にしている作業

- ローカルで使う小さな業務アプリや個人用ツールを作る
- UIの構造を見える形で管理し、部品を使い回す
- GUI編集とTypeScriptによる処理記述を併用する
- ProjectファイルやBundleを手元で保存・受け渡す

一般向けWebサービスのアカウント管理、クラウド保存、複数人の同時編集などは、現在の製品方針の対象外です。対応範囲は初版の仕様確定時に更新します。

初版公開前に、各ページの記述を実装と照合し、対応バージョン、使用例、制約、関連項目を記載します。
