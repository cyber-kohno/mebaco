初版のUIに沿って、次の完成例を作るチュートリアルを配置します。手順ごとにスクリーンショット、期待されるツリー、実行結果、つまずきやすい点を掲載します。

```text
Project
└─ App
   └─ Entry
      └─ Component
         ├─ Store / State: count = 0
         └─ Elements
            ├─ Text: countを表示
            └─ Button: Actionでcountを増やす
```

## チュートリアルで扱う操作

- Projectを新規作成して名前を付ける
- AppのEntryからComponentを指定する
- State、Text、Buttonを追加する
- 値を式で表示し、クリックActionを接続する
- Previewで動作を確認してProjectを保存する

このページは、初版完成時に実際の操作名・初期テンプレート・画面キャプチャに置き換えます。
