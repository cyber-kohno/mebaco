このガイドは、Mebacoを初めて使う人がインストールから最初のProjectの起動まで進めるための入口です。初版で確定する画面表示と配布手順を反映して完成させます。

## 学ぶ順番

1. [インストール](/start/install/) — 対応環境とStudioの起動方法
2. [最初のProject](/start/first-project/) — Projectを作り、画面を表示する
3. [Projectの構造](/concepts/project-model/) — App、Entry、Componentの関係
4. [StateとAction](/guides/state-and-actions/) — 操作に応じて画面を変える
5. [アプリを配布する](/guides/distribute/) — BundleとClientの使い方

## 困ったとき

エラー表示や操作の意味は[トラブルシューティング](/troubleshooting/)を参照してください。設定項目の正確な意味は[リファレンス](/reference/)から要素ごとに調べられる構成にします。
